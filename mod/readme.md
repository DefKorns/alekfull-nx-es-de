# EmulationStation Theme: Alekfull NX

Alekfull NX for the EmulationStation port on the NES/SNES Classic. It has the system carousel with a fixed selector, the
game count with the favourites, and a list view with a cover and a metadata panel, one background per console.

Installs to `/etc/emulationstation/themes/alekfull_nx`. Pick it in the EmulationStation menu under UI Settings, Theme
Set. The list view is the `detailed` one: set the gamelist view style to `detailed` to use it.
